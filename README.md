 # FNP Sales Analysis Dashboard

## 📊 Project Overview

This project is an interactive sales analysis dashboard created using Microsoft Excel.

The objective of this project is to analyze FNP sales data and identify important trends related to revenue, orders, customers, products, occasions, and sales performance.

## 🎯 Project Objectives

- Analyze overall sales performance
- Identify top-performing products and categories
- Analyze revenue by occasion
- Understand customer purchasing patterns
- Identify monthly and hourly sales trends
- Compare sales performance across different categories
- Create an interactive dashboard for business insights

## 🗂️ Dataset

The project uses three datasets:

- *Customers* – Customer-related information
- *Orders* – Order and sales transaction information
- *Products* – Product and category information

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Dashboard Features

The dashboard includes:

- Total Revenue
- Total Orders
- Average Order Value
- Revenue by Category
- Revenue by Occasion
- Monthly Revenue Analysis
- Hourly Order Analysis
- Top Products
- Customer Analysis
- Interactive Slicers
